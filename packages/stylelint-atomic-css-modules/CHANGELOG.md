# Changelog

All notable changes to `@zslabs/stylelint-atomic-css-modules` are documented here.

## 0.1.0

- Initial release: `atomic-css-modules/no-non-composable` rule
- Warns on non-composable selectors and shorthand/longhand conflicts
- `selectors` / `declarations` options (both default `true`)
- Honors `/* atomic: skip */` the same way as the Vite plugin
